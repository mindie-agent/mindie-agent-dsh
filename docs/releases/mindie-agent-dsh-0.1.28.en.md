# mindie-agent-dsh 0.1.28: 9-Domain Bindings & Revocation Migration, Unified UTF-8 Spool Cursors, and Host Lifecycle Hardening

[中文](mindie-agent-dsh-0.1.28.md)

- **Complete 9-package runtime lock, 9-domain single-lock binding, and revocation migration**: Adds [`product-contract.json`](../../product-contract.json) (`mindie-product-contract/1`) and pins all 9 runtime packages across [`pyproject.toml`](../../pyproject.toml), [`runtime-requirements.txt`](../../runtime-requirements.txt), and [`uv.lock`](../../uv.lock) (adding `npu-top 0.3.5` alongside `mindie-harness >= 0.1.5`, `mindie-knowledge 0.13.25`, `remote-dev 0.11.15`, `mindie-diagnostics 0.5.17`, `mindie-coordinator 0.7.14`, `mindie-debugger 0.1.4`, `mindie-profiler 0.5.16`, and `mindie-sim 0.9.18`). Under `.dsh.json.update.lock`, `scripts/setup.py` migrates explicitly revoked (`status == "inactive"` / `enabled=0`) sessions and `attempts` across `admission_path` transitions, invokes `ensure_knowledge_binding(..., retire_previous=True, already_locked=True)` to provision all 9 content-addressed `engines/dsh/<20hex>/<domain>.engine.json` files (with DSH's loopback `summary_command`), and runs `maintain_runtime` GC; `setup.py sharing` enforces mutually exclusive `--status | --enable | --local-only | --disable` flags (`exit 2` on conflict).
- **Deleted `_knowledge_fallback` shadow shim and cold-seed byte-0 JSON-RPC purity**: Removes the legacy `_knowledge_fallback` / `DSHManagedAdapter` shadow fallback from `scripts/mindie_launch.py`, delegating directly to `ManagedMCPAdapter("dsh")` and `serve_mcp(..., managed=True)`. Cold-seed provisioning (`_bootstrap`) runs with `stdin=subprocess.DEVNULL` and `stdout=subprocess.DEVNULL` (forwarding `stderr` only on non-zero exit) so `{"status": "provisioned", ...}` never corrupts byte 0 of live MCP JSON-RPC `stdout` or consumes client `stdin`.
- **Unified byte-addressed UTF-8 spool transcript identity and bounded eviction (`scripts/dsh_transcript.py`)**: Projects concatenated-zstd `session.v4.jsonl.zstd` logs into `<state_dir>/spools/<24hex>.jsonl` plus sidecar `.meta.json` so `identify(native_zstd) == identify(spool_path)` and `FileIdentity`, `capture_source()`, `read_material()`, and `read_increment()` share one byte-addressed UTF-8 coordinate space across multi-turn appends. `capture_source()` verifies native session `cwd` containment within the authorized `project_root`, decompression is bounded at `32 MiB` / `5.0s`, and cold spool eviction bounds `<state_dir>/spools/` to `<= 64` files while skipping locked active readers.
- **Node Python resolution, omitted-`sessionId` mount race safety, and non-blank `turn` guard**: `paths.cjs` strips UTF-8 BOM (`\uFEFF`) before JSON parsing and adds `resolvePythonCommand` (checking `venvPython`, `MINDIE_DSH_PYTHON`, `uv run --no-project --python >=3.11,<3.15`, and verified `PATH` interpreters while rejecting `Microsoft\WindowsApps` / 0-byte stubs and never returning bare `'python'` on `win32`). `host.mjs` resolves omitted-`sessionId` agents once into a cached `dsh-conn-<uuid>` identity and tracks per-mount `closed` state across `await` boundaries to dispose late or partial MCP fibers cleanly on mid-mount disposal or same-ID replacement. `host3.mjs` skips `agent/turn-stopping` capture when `turn` is omitted or blank.
- **Lean production budget and CI host acceptance (`verify-host-plugin.yml`)**: Keeps total production LOC at `1,466` (`<= 1,500` across `paths.cjs`, `host.mjs`, `host3.mjs`, and `scripts/{mindie_launch,dsh_transcript,setup}.py`) and wires `mindie-agent/mindie-bench/.github/workflows/verify-host-plugin.yml@main` (`host: dsh`) into `.github/workflows/ci.yml`.
