# mindie-agent-dsh 0.1.28：9 领域绑定与撤权迁移、统一 UTF-8 Spool 游标及宿主生命周期加固

[English](mindie-agent-dsh-0.1.28.en.md)

- **补齐全部 9 大运行时包锁定、9 领域单锁绑定与撤权跨库迁移**：新增 [`product-contract.json`](../../product-contract.json)（`mindie-product-contract/1`），并在 [`pyproject.toml`](../../pyproject.toml)、[`runtime-requirements.txt`](../../runtime-requirements.txt) 与 [`uv.lock`](../../uv.lock) 中完整锁定全部 9 个运行时组件（新增 `npu-top 0.3.5`，同步 `mindie-harness >= 0.1.5`、`mindie-knowledge 0.13.25`、`remote-dev 0.11.15`、`mindie-diagnostics 0.5.17`、`mindie-coordinator 0.7.14`、`mindie-debugger 0.1.4`、`mindie-profiler 0.5.16`、`mindie-sim 0.9.18`）。`scripts/setup.py` 在 `.dsh.json.update.lock` 排他锁下先迁移历史 `dsh/config.json`、`dsh.engine.json` 及旧 `domain_configs` 中的显式撤权会话（`status == "inactive"` / `enabled=0` 及对应 `attempts` 记录），再调用 `ensure_knowledge_binding(..., retire_previous=True, already_locked=True)` 生成内容寻址的 `engines/dsh/<20hex>/<domain>.engine.json` 9 领域配置（注入回环 `summary_command`）并执行 `maintain_runtime` GC；`setup.py sharing` 对 `--status | --enable | --local-only | --disable` 施加互斥参数校验（冲突时以 `exit 2` 显式拒绝）。
- **删除 `_knowledge_fallback` 影子桩与冷启动 Byte-0 JSON-RPC 纯净性**：移除 `scripts/mindie_launch.py` 中的旧版 `_knowledge_fallback` / `DSHManagedAdapter` 影子回退实现，MCP 服务统一直接委托 `ManagedMCPAdapter("dsh")` 与 `serve_mcp(..., managed=True)`；冷启动种子引导（`_bootstrap`）将子进程隔离为 `stdin=subprocess.DEVNULL` 与 `stdout=subprocess.DEVNULL`（错误流单独捕获转发至 `stderr`），确保种子输出的 `{"status": "provisioned", ...}` 绝不污染实时 MCP JSON-RPC `stdout` 首字节或抢读客户端 `stdin`。
- **统一字节寻址 UTF-8 Spool 转录身份与有界冷淘汰（`scripts/dsh_transcript.py`）**：将 DSH 原生多帧拼接 `session.v4.jsonl.zstd` 投影至 `<state_dir>/spools/<24hex>.jsonl` 及 `.meta.json`，令 `identify(native_zstd) == identify(spool_path)`，使 `FileIdentity`、`capture_source()`、`read_material()` 与 `read_increment()` 共享同一 UTF-8 字节坐标空间（消除压缩流与解压流跨回合追加时的锚点/游标错位）；`capture_source()` 强制核验原生会话 `cwd` 位于授权 `project_root` 之内，解压限制为 `32 MiB` / `5.0s`，冷 Spool 数量上限为 `<= 64` 并通过非阻塞 `.lock` 跳过在读文件。
- **Node 侧解释器解析、无 `sessionId` 挂载竞态防护与非空 `turn` 门禁**：`paths.cjs` 在解析配置前剥离 UTF-8 BOM 并新增 `resolvePythonCommand`（按序解析 `venvPython`、`MINDIE_DSH_PYTHON`、`uv run --no-project --python >=3.11,<3.15` 与 `PATH` 解释器，全面剔除 Windows Store `WindowsApps` 空字节别名，且在 `win32` 下绝不退回裸 `'python'`）；`host.mjs` 对缺省 `sessionId` 的 Agent 单次解析并缓存 `dsh-conn-<uuid>` 连接身份，通过跨 `await` 的 `closed` 挂载记录安全回收中途销毁或同 ID 替换的迟到 MCP Fiber；`host3.mjs` 在 `agent/turn-stopping` 缺少有效非空 `turn` 时直接跳过采集。
- **生产代码规模收敛与 CI 原生宿主验收（`verify-host-plugin.yml`）**：6 个薄生产文件（`paths.cjs`、`host.mjs`、`host3.mjs`、`scripts/{mindie_launch,dsh_transcript,setup}.py`）合计 `1,466` 行（严守 `<= 1,500` 上限），并在 `.github/workflows/ci.yml` 接入共享 `verify-host-plugin.yml`（`host: dsh`）宿主验收门禁。
