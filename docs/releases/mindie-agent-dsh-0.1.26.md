# mindie-agent-dsh 0.1.26：Great Subtraction、薄插件边界与安装体验升级

[English](mindie-agent-dsh-0.1.26.en.md)

- **Great Subtraction（大幅精简）**：删除 26 个历史重复运行时模块，`scripts/` 仅保留 `mindie_launch.py`、`dsh_transcript.py`、`setup.py`；Host 边界仅保留 `paths.cjs`、`host.mjs`、`host3.mjs`。六者合计 `<= 1,200` 行（本次约 1,100 行），MCP 路由、运行时准备、共享/更新、锁、存储 GC 与 7 宿主适配全部委托 `mindie-harness`（`API_VERSION = 1`），冷启动继续校验内置 `assets/mindie-harness-seed.pyz` 与 `seed-lock.json`。组件 Git SHA 与 `0.1.25` 完全一致。
- **两套默认常驻 MCP 与零前置门禁**：`host.mjs` 为每个会话挂载 `remote-dev`（恰好 14 个 `dsh` 原生工具）与 `mindie-tools`（确定性组件 + 只读 `mindie_doctor` + 5 个 `knowledge_*`），统一经 `scripts/mindie_launch.py --config <dsh.json> mcp <surface>` 和 `ManagedMCPAdapter("dsh")` 提供，零 `_meta`、零 `request_nonce`、零 `context_file`；第二个 attach 失败时回滚第一个。所有 Node `spawn` 带 `windowsHide: true`，后台任务仅在非 `win32` 使用 `detached: true`。
- **`host3.mjs` 全 Node 侧授权与摘要桥**：`agent/turn-stopping` 先以纯 Node 读取 `mindie-community.json`（`enabled` + `project_roots`）与 `mindie-consent.json`（`contribute`/`local-only`），通过后才查找 `session.v4.jsonl.zstd` 或派发子进程；子代理（`delegationDepth > 0`）永不采集。回环 `/summary` 使用 Bearer token、512 KiB 上限并支持 `mindie-summary-request/1` + `mindie-distill-request/1`；无运行中 agent 时以 `setTimeout`/`setInterval`（均 `unref()`）触发窗口less `update --background`。
- **确定性 1 条命令安装与 3 问动态引导**：`uv run https://github.com/mindie-agent/mindie-agent/releases/latest/download/install.py --host dsh` 完成运行时预热与 `dsh.json`/`dsh.engine.json` 写入；首次配置使用 3 个 `gh` 感知问题（工作区、体验/隐私层级、一步 SSH NPU），`gh` 仅推荐用于 `contribute`，永不阻断 `local-only`/`read-only`。完成后执行只读 `mindie_doctor` 就绪汇总，并在 `gh` 已登录且用户同意时附一行礼貌的 Star 提示；`SKILL.md` 明确 **Non-Blocking Task Continuity Rule**：任何 MindIE 工具失败只报告一次具体错误（先核对不确定的远端写入），随后立即改用原生 `ssh`/`scp` 或本地脚本继续。
- **测试与发布校验**：`tests/` 重建为快速、隔离的契约套件（`conftest.py`、`test_dsh_transcript.py`、`test_dsh_thin_plugin.py`、`test_dsh_host.mjs`），覆盖 seed 校验、canonical `dsh.json`/legacy `config.json` 优先级、`backgroundSpawnOptions('win32').detached === false`、`Stop` 快速路径与 `contribute`/`local-only` 授权对等（保留显式 `Admission` 撤销）、14 个 `remote-dev` 工具与零 `_meta` 的真实 `knowledge_query`、`setup.py init/sharing/release-metadata`，以及 `/summary` Bearer/512 KiB 与窗口less spawn。`harness-compatibility.json` 的每个 `code_paths`/`test_ids` 均指向存活文件，并由 `setup.py release-metadata` 校验后输出 `mindie-plugin-release/1`。
